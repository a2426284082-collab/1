# 猫源工作台 v2.2.7（APK 反编译重建源码）

这是从现有 APK 恢复出的可重新构建工程。由于原始 Android Studio 工程已经遗失，本包使用 Apktool 的 Smali 工程格式，而不是原始 Java/Gradle 项目。

## 本版修改

- 导入失败后新增“放弃本批次，重新开始”。该操作会清除失败批次、当前截图和当前视频的待处理状态，不会再次卡在“重试失败批次”。
- 新猫咪恢复为直接创建飞书记录，不再尝试更新已清空的旧记录，从根源上避开 `NumberFieldConvFail`。
- 禁用“识别为已售后更新原记录”以及底层飞书更新接口；本版只允许新增记录。
- 三条导入路径统一标准化品种和毛色，禁止品种字段出现括号、别名、毛色和营销词。
- 年龄统一成“2个月”等文字格式；只有原文明确出现时才填写，不凭外观猜测。
- 新增飞书文本字段“疫苗”和“描述”；疫苗按固定值提取，描述生成40至80字的真实展示文案。
- 首页直接显示 `v2.2.7`，便于确认安装版本。
- 版本号更新为 `2.2.7`（versionCode `227`）。
- “描述生成提示词”放入固定设置，可直接修改并随全部设置一起备份、恢复；工作模式每次识别都会优先附加这段要求。
- 展示描述写入前强制清洗：移除“视频中/图片中”等机器口吻，并删除包含内部价格、疫苗针数、健康或无癣承诺的句子。
- 修复 `automateTimeline` 中配置对象寄存器被提示词字符串覆盖、导致 Android `VerifyError` 拒绝加载 `ApiClient` 的问题。
- 后台任务提交时立即保存待处理文件；发生致命异常或进程中断后仍可重试。
- “AI识别中”超过三分钟没有任何状态更新时自动转为失败，不再无限假运行。
- 超时或异常转为失败后显示“放弃本批次，重新开始”，可人工解除卡住状态。
- 固定设置支持生成完整备份码，并在卸载重装后粘贴恢复；备份包含飞书与 AI 密钥，必须按密码保管。
- 写入飞书前增加确定性的品种与毛色归一化，不再只依赖 AI 是否遵守提示词。例如：`英国短毛猫/英短 → 英短`、`缅因/缅因猫 → 缅因猫`、`海豹双色/海双 → 海双`。

## 重新构建

需要 Java 运行环境、Apktool 2.11.1 和 APK 签名工具。

```bash
java -jar apktool_2.11.1.jar b . -o 猫源工作台-unsigned.apk
java -jar uber-apk-signer-1.3.0.jar -a 猫源工作台-unsigned.apk -o signed
```

使用同一签名证书才能直接覆盖安装后续版本。请保存以后正式发布所用的 keystore；不要每次生成新证书。

## 重要说明

- 本工程是从 APK 恢复的 Smali 源码，可修改、可重建，但可读性不如原始 Java 工程。
- 当前成品 APK 的签名与遗失源码时的旧 APK 签名不同。首次安装本重建版本时，如果系统提示签名冲突，需要先导出设置备份，再卸载旧版后安装。卸载会清除应用数据，但可通过备份码一键恢复。v2.1.1 及之后的重建版本升级到 v2.2.7 可直接覆盖安装。
- APK 已完成重新构建、包名/版本检查、ZIP 对齐及 v2/v3 签名验证；真实飞书账户下的写入行为仍需在手机上做一次实际导入测试。
